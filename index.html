Как проходит тест

  • Вопросы выпадают по одному в произвольном порядке и не повторяются: за одно прохождение каждый вопрос выбранного набора встречается ровно один раз.
  • Часть заданий — с несколькими правильными ответами; такие помечены значком и требуют нажать «Ответить».
  • Правильный ответ подсвечивается зелёным, неправильный — красным.
  • Каждый ответ заносится в таблицу результатов внизу страницы.
  • Все вопросы выбранного набора = 100%. Минимальный проходной порог — 70%.
  • Любой ответ можно перепроверить по первоисточнику: откройте исходный PDF — у каждого вопроса есть ссылка на его страницу (экзаменационные — стр. 1–17, дополнительные — стр. 16–93).
  • Прогресс сохраняется в браузере после каждого ответа: при обрыве интернета, закрытии вкладки или перезагрузке страницы тест продолжится с того же места, а таблица результатов восстановится.
